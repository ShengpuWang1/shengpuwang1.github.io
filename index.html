Project 01

Compact Boolean Networks

ETH Zürich · Research assistant · Sep 2025–Mar 2026

Implemented and improved compact convolutional Boolean networks, including custom CUDA convolution operators. The project combines architecture design with efficient implementation and evaluation on MNIST and CIFAR-10.

Achieved comparable or better classification accuracy with 3–45× fewer neurons than evaluated baselines.

Project 02

Hybrid Quantum-Classical Learning

ETH Zürich · Master’s thesis · Apr 2024–Jan 2025

Implemented and trained hybrid quantum-classical models to recognize topological quantum phases on 4- and 9-qubit processors. Combined parameterized quantum circuits with classical post-processing and evolutionary optimization.

Evaluated convergence and classification across training sets and initialization strategies using verification sets and ROC curves.

Evolutionary strategies / Classification / ROC analysis

Project 03

Signal-Chain Simulation & Precompensation

Zurich Instruments AG · Internship · Oct 2023–Mar 2024

Built numerical models connecting pulse generation, analog signal-chain imperfections, and qubit dynamics to gate fidelity. Used Python, LTspice, and quantum simulation to study distortion and noise and optimize pulse parameters.

Assessed simpler precompensation filters and the tradeoff between computational requirements and signal quality.

Numerical simulation / Signal processing / Optimization

Project 04

Genetic Algorithm for Readout Optimization

Karlsruhe Institute of Technology · Research internship · Jul–Oct 2021

Developed a genetic algorithm to search for superconducting-qubit readout pulse shapes. Candidate waveforms were evaluated through IQ measurements, with signal-to-noise ratio guiding selection, crossover, and mutation.

Compared optimized pulses with rectangular baselines and examined the separation and spread of readout distributions.

Genetic algorithms / Experimental optimization / Signal-to-noise ratio

Project 05

Resonance Detection with the Hough Transform

University of Western Australia · Remote internship · Jul–Aug 2021

Developed a resonance detection workflow using both amplitude and phase of transmission data. Detecting circular structures in the complex plane identified difficult cases such as resonance valleys and overlapping modes.

Packaged the analysis in a Python interface for fitting frequencies and quality factors and exploring temperature dependence.

Feature extraction / Complex-valued data / Python

Project 06

Rydberg EIT Response Simulation

ETH Zürich · Semester project · Feb–Jun 2023

Built a Python tool for calculating electromagnetically induced transparency (EIT) responses in a Rydberg system. The interface compares three-level and interacting four-level models and supports parameter exploration.

Simulated photon distributions at selected measurement points to study qubit detection.

Numerical modeling / Quantum dynamics / Scientific software

Project 07

Independent engineering project

Built a receiver and processing pipeline that turns aircraft radio signals into mapped flight information. The workflow combines 1090 MHz reception, down-conversion, decoding, and geographic visualization.

Connected raw signals to interpretable records including callsign, altitude, speed, and coordinates.
