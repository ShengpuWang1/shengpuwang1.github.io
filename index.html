Project 01

Compact Boolean Networks

ETH Zürich · Research assistant · Sep 2025–Mar 2026

Conventional neural networks rely on floating-point arithmetic, which can make inference expensive on resource-constrained hardware. Boolean networks instead compute with logical operations, but learning a compact network without sacrificing accuracy is difficult because both the operations and their connections are discrete. This project investigated how to improve that accuracy–size tradeoff for image classification.

I implemented and improved compact convolutional Boolean networks, including custom CUDA convolution operators. The work combined model architecture design with efficient implementation and evaluation on MNIST and CIFAR-10. Against the evaluated baselines, the models achieved comparable or better classification accuracy with 3–45× fewer neurons.

The figure compares classification accuracy on the vertical axis with neuron count on the horizontal axis, shown on a logarithmic scale. Each curve represents a method evaluated at different model sizes. A point farther up and to the left offers higher accuracy with a smaller network. The blue “Ours” curve illustrates the project’s central outcome: competitive classification with substantially more compact models.

Efficient ML / CUDA / Discrete optimization

Project 02

Hybrid Quantum-Classical Learning

ETH Zürich · Master’s thesis · Apr 2024–Jan 2025

Identifying a quantum phase requires recognizing correlations across a many-qubit state, rather than inspecting each qubit independently. My master’s thesis explored whether a trainable hybrid quantum-classical model could distinguish topological surface-code states from trivial states on noisy superconducting hardware. I implemented and trained models on 4- and 9-qubit processors using evolutionary strategies to optimize circuit parameters.

The figure shows the 9-qubit classifier. Each horizontal wire represents one qubit. “Prep.” prepares the input state, and the dashed PQC region is the parameterized quantum circuit: boxes labeled θ are local Y-rotation gates, while vertically connected circles labeled φ are two-qubit controlled-phase gates. These alternating layers transform the input before measurement M. CPP denotes classical post-processing, which turns the measured bitstrings into a prediction about the input state’s phase.

The project demonstrated experimental training and phase classification while examining how training data and initialization affect generalization. I compared convergence, phase-boundary detection, and single-shot classification using verification states and ROC analysis. A key finding was that learning to separate a narrow training set can miss the broader distinction between phases; more representative trivial-state training data improved verification performance. The work established a practical experimental learning procedure, without claiming a demonstrated quantum computational advantage.

The second figure shows phase-boundary detection with a trained 4-qubit model. The horizontal axis sweeps through ground states |ψ(h)⟩ as the perturbing field h increases: the left end is topological, and the states move toward the trivial phase on the right. The averaged model output decreases along this sweep, reflecting a lower predicted likelihood of the topological phase. Blue dots show the original outputs and the solid blue line shows a smoothed response. The blue dotted line marks the boundary inferred from the strongest change in that response, while the orange dotted line marks the theoretical reference. Their separation makes the quality of the boundary estimate visible. This 4-qubit result complements the 9-qubit circuit above, illustrating how a trained circuit’s measurements can be used to identify a change of phase.

Project 03

Signal-Chain Simulation & Precompensation

Zurich Instruments AG · Internship · Oct 2023–Mar 2024

Quantum-control electronics must deliver accurate pulses, but adding digital precision and correction stages consumes hardware resources. This internship investigated how device imperfections propagate through a control signal chain and affect the fidelity of qubit operations. I built numerical models combining pulse generation, LTspice analog-circuit simulation, and qubit dynamics, then optimized pulse parameters and studied noise and distortion.

The figure examines one engineering choice: simplifying the finite impulse response (FIR) filter used for precompensation. Precompensation modifies the outgoing waveform to counteract distortion in the analog signal chain. The horizontal axis indexes filter coefficients, and the vertical axis shows their values. Blue points represent a 36-tap filter at full resolution; red points show a 20-tap alternative using reduced time resolution in part of the kernel. Green dashed markers indicate the resolution intervals.

The smaller, slowly varying coefficients in the kernel’s tail motivate the reduced-resolution treatment. In the corresponding simulation comparison, both compensation schemes improved iSWAP gate fidelity relative to the distorted, uncompensated signal, with similar infidelity for the two filters. This supported reducing filter complexity while retaining the modeled control quality, and provided a way to evaluate resource–accuracy tradeoffs before committing to hardware changes.

Numerical simulation / Signal processing / Optimization

Project 04

Genetic Algorithm for Readout Optimization

Karlsruhe Institute of Technology · Research internship · Jul–Oct 2021

Reading out a superconducting qubit means inferring its state from a noisy microwave measurement. The shape of the probing pulse affects how clearly the measurement separates the ground and excited states. This research internship investigated whether a genetic algorithm could find better readout waveforms than a conventional rectangular pulse, using experimental measurements as the optimization objective.

I encoded candidate pulse shapes as binary sequences and evaluated a population of waveforms using IQ measurements. Pulses with higher signal-to-noise ratio were more likely to be selected as parents; crossover and mutation generated the next population. The figure shows the resulting type of measurement data: two-dimensional histograms in the in-phase/quadrature plane for prepared ground and excited states. Color represents sample counts, and the red lines show a discrimination boundary. Better separation and tighter distributions make state assignment more reliable.

The experiments found pulse shapes that improved the readout SNR relative to rectangular baselines. In one documented run, the best rectangular-pulse SNR was 2.2138 and the genetic search reached 2.7168 after 50 generations, using the distinct attenuation settings described in the report. The result demonstrates experimental waveform optimization under noise; it does not establish a universal fidelity improvement across all operating conditions.

Project 05

Resonance Detection with the Hough Transform

University of Western Australia · Remote internship · Jul–Aug 2021

Resonator measurements contain information about both the amplitude and phase of a transmitted signal. Standard peak detection can miss a resonance when interference turns its amplitude peak into a valley, or when nearby resonances overlap. This project developed a detector that uses the geometry of the full complex transmission coefficient instead of relying only on prominent amplitude peaks.

After correcting cable delay, the algorithm searches for circular arcs in the complex plane using a Hough transform. Candidate regions are extended and fitted to extract resonant frequencies and quality factors. The figure shows a difficult resonance-valley example. The upper-left panel is the measured amplitude feature; the upper-right panel plots the complex transmission data and its fitted circle. The lower panels compare measured amplitude and phase with the fitted response. Blue traces are the data, and orange traces are the fits.

The agreement across the complex-plane, amplitude, and phase views supports identifying the feature as a resonance even though it is not an ordinary peak. The report also demonstrates detection of overlapping modes. I packaged the analysis in a Python interface for fitting and tracking modes across temperature. The outcome was a more informative analysis tool for these difficult spectra, with an explicit tradeoff between search resolution and runtime.

Project 06

Rydberg EIT Response Simulation

ETH Zürich · Semester project · Feb–Jun 2023

Electromagnetically induced transparency (EIT) uses coupled atomic transitions to change how a weak probe field passes through an atomic ensemble. An interacting Rydberg qubit can modify that response, creating a possible optical signature of its presence. This semester project built a numerical tool to compare the response of an ensemble alone with that of an ensemble coupled to a Rydberg qubit, and to explore measurement conditions for qubit detection.

The figure presents the physical model. On the left, the probe and coupling fields connect the ground, intermediate, and Rydberg levels; the additional Rydberg state and exchange interaction introduce the qubit-dependent response. On the right, the Hamiltonian specifies the couplings, detunings, and interactions. The density-matrix evolution equation includes dissipative terms, and the transparency expression connects the simulated atomic coherence to an optical observable.

I implemented a Python interface that compares three-level and interacting four-level models while allowing users to vary parameters. After choosing a measurement point on the calculated EIT response, users can inspect simulated photon distributions. The result is an exploratory scientific tool linking a microscopic dynamical model to a measurable detection signal, rather than a claim of experimentally demonstrated readout performance.

Project 07

Software-Defined Flight Radar

Independent engineering project

This independent project turned received aircraft radio signals into readable flight information and a geographic display. The aim was to build an end-to-end system connecting radio reception, digital signal processing, message decoding, and visualization, rather than starting with an already decoded flight-data service.

The figure shows the reception and decoding stages alongside an example of the system’s map output. A 1090 MHz bandpass filter selects the relevant radio band, and a down-conversion stage prepares the signal for digital processing. The software then recovers and decodes messages into records such as callsign, altitude, speed, and coordinates. The map screenshot shows how those decoded records become spatial information a user can inspect.

The repository includes the reception and IQ-conversion code, decoding logic, orchestration script, and an example generated map. The main outcome was a working chain from captured radio samples to interpretable flight records and mapped positions. The website figure is a recorded example of that output, rather than a live aircraft feed; the project demonstrates integration across hardware, signal analysis, and software presentation.
